# Implementation milestones

The detailed approved plan is saved in the originating Copilot session's
`plan.md`. This file describes repository deliverables, not completion claims.

1. Independent repository, reproducible CLI and source contract.
2. Immutable held-data imports, complete returns and exclusion queries, coverage
   report, focused tests and offline replay.
3. Election-map-qualified presidential baselines; state benchmarks for Senate;
   provisional 2026 separately versioned.
4. Verified FEC/Bioguide/ICPSR identities and dated incumbency/service.
5. Pre-election legislative measures and documented background, with coverage
   audits covering losing candidates.
6. Cross-fitted constituency-adjusted performance and chamber-specific
   characteristic associations; grouped/chronological validation and uncertainty.
7. Research report, restrained charts and complete permitted data/code downloads.
8. Reconciled, offline-reproducible release and evidence-backed findings.

Do not silently expand completed milestones when later data are still missing.
No website or automatic public publication is part of the initial scope.
