# V6: requirements-led acquisition loops

Start from V5 commit `9f6713cf126895d1f631e7972bf157229f763861`.
Freeze V1-V5 outputs, all 823 normalized observations and candidate-contest
identities. Retain all 449 Democrats, 405 eligible performance comparisons
and fifteen trait blocks. Acquisition is not the same as analytical eligibility.

Each loop selects sources using the missing factual requirement and actual
candidate overlap, checks earlier receipts, retrieves originals once, reviews
bounded literal claims and records failures. Ingest before deciding which
models need recomputation. Checkpoint and push coherent research milestones.

## Initial source-family opportunities

  nominees, including nonincumbent Chris Beck. Candidate-authored education,
  occupation and prior-government fields may fill factual requirements;
  attendance and missing sections never establish graduation or nonservice.
* Washington's 2026 official guide could cover nonincumbents John Duresky and
  Carmela Conroy. The landing page returned HTTP 403 during discovery; do not
  retry that denied page through another client or count its shell as evidence.
* Complete state legislative directories are useful only where an independently
  linked native nominee actually appears. Texas's current 89th-Legislature
  House table does not cover the Democratic nonincumbent names in this queue;
  a catalog hit alone is not a reason to download or count new observations.
* Further loops prioritize explicit religious descriptions, service histories
  and identity bridges for the twelve remaining Democratic incumbency holds.
  Choose bulk questionnaires/directories before candidate-specific follow-up.

Unknowns, source dates, conflicting claims and historical populations are
preserved. Historical religion is not automatically current affiliation;
source-recorded identities are not inferred from names, photographs or caucuses.
New negative office/government/military labels require explicit support.
Before-2026 office history is distinct from office before first House entry.

The fifteen-block model design, full-family correction, geographic/category
support, state/person separation, training-only preprocessing and complete
deletion pipeline remain unchanged. No new model search or relaxed support
gate is justified by weak findings. Local reports and both complete downloads
must retain all prior frozen releases. No website deployment.
